# Marketing & Creative Command Centre

This workspace is one connected Marketing architecture:

- NEO PULSE — command hub
- NEO LAUNCH — Deals and approved Sales offers
- NEO FLOW — campaigns, content and immutable versions
- NEO GREENLIGHT — version-specific approval
- NEO PLAN — projected and manual calendar activity
- NEO SIGNAL — attribution-backed business outcomes
- NEO RADAR — deterministic CRM intelligence and explicit opportunities
- NEO STUDIO — NeoTrio ideas, production, library and performance

Authoritative records are reused across modules. External provider availability never controls whether internal workflows can complete. This documentation describes internal UAT readiness, not production readiness.
