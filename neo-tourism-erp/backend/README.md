# Neo Tourism ERP 2.0 Backend

NestJS API foundation for the Neo Tourism internal ERP system.

## Development

```bash
npm run start:dev
```

The API runs at [http://localhost:3001](http://localhost:3001).

## Health check

```text
GET http://localhost:3001/health
```

## Checks

```bash
npm run lint
npm run build
npm run test:e2e
```
